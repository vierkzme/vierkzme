### ⚡ Engineering Focus

- 🌐 **Full-Stack Development:** Building responsive, accessible frontends with **React & Tailwind CSS** backed by robust RESTful APIs using **Node.js (Express)** and **Python (FastAPI)**.
- 🗄️ **Data Architecture & Quality:** Designing relational schemas with **PostgreSQL & Prisma ORM**, containerized via **Docker**, and validated with **Jest** automated testing.
- 🧠 **Machine Learning & NLP:** Transforming raw data into actionable insights and intelligent features using **Scikit-Learn, spaCy, NLTK, Pandas,** and **Power BI**.
